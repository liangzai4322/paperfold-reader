# 纸间

[手机打开纸间](https://liangzai4322.github.io/paperfold-reader/)

把长文粘贴成一本可以翻页的书。自动整理 Markdown 的标题、强调、链接、表格和列表。轻点书页两侧均可向前翻页，也可以轻扫、拖页角或使用方向键。

点一下书页中央，打开翻页模式、字号、进度和全屏设置。默认单面模式。切换为双面模式后，左侧往回，右侧往前。纸间会记住选择。

在阅读设置中点「外观」切换字体和背景。字号、字体与背景会在本机保存，换一篇文章后继续使用。附带字体的来源和许可证在 `docs/fonts/`。

在手机上长按正文，拖动选区后点「复制」。电脑上可以拖选正文并复制。

点「全屏」铺开书页。要退出时，再点中央，然后点「退出全屏」。浏览器限制系统全屏时，书页会铺满网页可用区域。

导入的文章及进度保存在书架里。首页的「云同步」可以连接自己的 HTTPS 服务，在手机和网页之间同步书架。AI 可使用独立密钥把文章直接放进书架。见 [部署与接口说明](server/README.md)。

## 本地运行

运行 `npm run dev`，再用浏览器打开 [本地阅读器](http://127.0.0.1:4173)。此命令使用 Python 3 启动静态服务。核心测试用 Node.js 运行 `npm test`。

## 发布与封装

GitHub Pages 以 `main` 分支的 `/docs` 目录为源。网页资源使用相对路径。`docs` 也是可供 Capacitor 使用的 Web 目录。分页算法由浏览器测量注入，存储在独立模块，后续可以接入原生存储与文件导入。

安卓 1.1.0 起可在应用内点「检查更新」。安装包下载后会校验哈希、包名和签名，再由安卓确认安装。发布新版时用同一签名构建递增版本号的 APK，将 `Paperfold-<版本>-android.apk` 上传到 `android-v<版本>` 的 GitHub Release，再更新 `docs/android-update.json`。
